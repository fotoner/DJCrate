# 바꾼 파일 → 늘 함께 돌릴 시험(scripts/affected-tests.py가 읽는다). 사람이 관리한다.
# 기호 이름으로 고르는 기본 규칙에 더한다. 안전 시험(라이브러리·USB·사용자 데이터를 지키는 시험)은 경로로 넓게 고른다:
# 프로세스로 띄우는 CLI 시험·반환값으로만 닿는 값 타입은 기호 grep에 걸리지 않는다. 그 밖은 대략적이어도 되고(놓친 몫은
# 릴리스 전체 검사가 덮는다), 놓친 회귀가 나오면 여기에 줄을 더한다.
# 적은 Suite가 Tests/에 없으면 affected-tests가 실패한다(이름을 바꿨으면 여기도 고친다).
#
# group <이름>              묶음 시작
# when <glob>               이 경로가 바뀌면 묶음을 켠다(`*`는 한 폴더 안, `**`는 하위 폴더까지). 맞는 파일이 하나도 없으면
#                           affected-tests가 실패한다(오타·파일 이동으로 묶음이 소리 없이 꺼지지 않게)
# maybe <glob>              when과 같되 맞는 파일이 없어도 된다(앞으로 옮길 자리)
# suite <시험 타깃>.<Suite>  더할 Suite
# target <시험 타깃>         더할 시험 타깃 전체
# check <검사>              켤 가벼운 검사(write-coverage·translations·imports·docs·harness·scripts)
# note <글>                 고른 범위와 함께 출력할 안내
# require <글>              --changed가 대신하지 않는 필수 검사. 고른 범위와 끝 요약에 ⚠로 다시 낸다
# none                      시험이 없는 파일로 인정(없으면 규칙 밖 파일은 전체 검사로 넓힌다)
# needs <시험 타깃> <제품>   그 타깃을 빌드할 때 제품도 빌드한다
