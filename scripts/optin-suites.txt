# 환경 변수가 있어야 도는 선택 실행 Suite의 목록(scripts/affected-tests.py가 읽는다). 사람이 관리한다. 규칙은 docs/ci.md "선택 실행 장치".
# 시험 파일의 `.enabled(if: …environment["…"])`와 이 목록이 어긋나면 `affected-tests.py --check-map`과 --changed가 종료 코드 2로 끝난다.
# Suite 전체를 `@Suite(.enabled(if:))`로 걸거나, Suite의 `@Test`를 모두 그렇게 걸면 선택 실행이다. 일부 시험만 거는 Suite는 적지 않는다.
#
# <종류> <시험 타깃>.<Suite> <변수=켜는 값> [<변수=켜는 값> …]
#   변수 중 하나라도 있으면 돈다(Swift의 `!= nil`이라 빈 값도 켠 것이다). 첫 변수가 안내에 먼저 나온다. 값에 빈칸을 쓰지 않는다.
#   regression  안 돌면 회귀를 놓치는 시험. --changed가 직접 골랐는데 변수가 없으면 "건너뜀" 경고를 남긴다.
#   tool        픽스처·실험 재현 도구. 안 돌아도 회귀가 아니라 경고하지 않는다. 경로를 받는 변수에는 임시 폴더만 준다(SAFE-7·SAFE-9).
# 고른 Suite가 모두 건너뛰어져 "실제로 완료한 시험이 없습니다"로 실패하면(check.sh) 두 종류 모두 이 목록으로 원인과 할 일을 안내한다.
