# 워커 지시서 틀

서브에이전트·다른 세션·워커에게 일을 맡기는 지시서의 틀이다.

내장 Explore·Plan 서브에이전트와 새 세션은 이 대화를 모른다. 일부는 AGENTS.md도 받지 않는다. 그래서 지시서 하나로 일을 끝낼 수 있게 아래 칸을 모두 채운다. 병렬 워커는 파일이 겹치지 않게 나눈 일에만 쓴다.

```markdown
# <일 이름>

## 목표
<무엇이 되면 끝인지 한두 문장. 동작으로 확인할 수 있게>

## 범위 밖
<하지 않을 것: 고치지 않을 파일·기능, 미룰 결정. "버그를 찾으면 고치지 말고 보고" 같은 규칙>

## 작업 위치
- 워크트리: <절대 경로>(이 밖은 건드리지 않는다. cd 대신 절대 경로·git -C)
- 시작할 때 `scripts/worker-lock.sh take <일 이름>`. 이미 표시가 있으면 아무것도 고치지 않는다. 그 자리에서 멈춰 보고한다. 끝나면 `scripts/worker-lock.sh drop <일 이름>`
- 건드릴 파일: <경로 목록>  /  건드리지 않을 파일: <경로 목록>
- 파일 이동은 git mv. 커밋·푸시·git stash 금지(따로 허락한 경우만)

## 먼저 읽을 것
- AGENTS.md(안전 불변식·검증), 그리고 이 일에 걸리는 경로 규칙: <.claude/rules/… 목록>
- <관련 docs 절, 이슈 번호, 앞 단계 보고서>

## 안전(늘 지킨다)
- 실제 rekordbox 라이브러리·DJCrate 사용자 폴더에 쓰지 않는다. 시험·실험은 DJC_REKORDBOX_DIR=<사본>, DJC_HOME=$(mktemp -d)
- 실물 USB(/Volumes/*)에 쓰지 않는다. USB 쓰기 시험은 djc lab usb-image 디스크 이미지에만
- DB 사본·스냅샷·백업(클라우드 토큰)을 출력·커밋·로그에 넣지 않는다
- 쓰기 관문(RekordboxWriter.write·restore, RekordboxTrackWriter.add·delete, UsbWriter.write, UsbPhysicalWriteGate)의 위치·동작을 바꾸지 않는다

## 검증
- 편집 중: scripts/check.sh --quick --filter '^<타깃>\.<Suite>/'(TDD, 빨간색 먼저)
- 끝: scripts/check.sh --changed --base <작업 전 git write-tree 해시>  (전체 검사는 <조정자가 / 하지 않음>)
- 추가: <앱 자가 테스트·디스크 이미지 확인이 필요하면 그 인자>
- 같은 checkout 빌드 동시 실행 금지. 무거운 실행은 lockf /tmp/djc-heavy.lock, 소리는 /tmp/djc-audio.lock, 창은 /tmp/djc-gui.lock
- 긴 출력은 파일로 받고(> <로그 경로> 2>&1) 필요한 줄만 grep

## 보고(<보고서 경로>, 한국어, 짧게)
1. 바꾼 것: 파일 이동표, 새 타입·포트, 지운 시험 → 대체 시험
2. 확인한 것: 실행한 명령, 필터와 그 범위가 바꾼 영향을 덮는 근거, 통과·실패 수, 종료 코드, 시간(같은 기계 부하 uptime 함께)
3. 남은 것: 다음 단계로 넘길 것, 발견한 버그(고치지 않음), 결정이 필요한 것
4. 다른 파트와 겹칠 수 있는 파일과 그 안에서 바꾼 부분
마지막 응답에도 요약.

## 진행 기록
- 긴 일은 <진행 파일 경로>에 "다음 세션이 처음 읽을 것"을 맨 위에 두고 단계마다 고친다.
```

## 쓰는 요령

- 목표는 결과로 쓴다. "~를 옮긴다"보다 "~가 ~를 부른다. ~시험이 통과한다."가 낫다.
- 검증 명령은 필터까지 적는다. 필터를 워커가 추측하게 두지 않는다.
- 필터는 `scripts/affected-tests.py --files <경로…>`로 미리 볼 수 있다.
- 리뷰는 `.claude/agents/reviewer.md`에 맡긴다. 이 리뷰어는 정확성과 안전 규칙 위반만 본다. 스타일은 지적하지 않는다.
- 리뷰를 맡길 때는 계획과 diff 범위를 준다. "근거 줄과 재현 방법"도 함께 달라고 한다.
- 맡긴 뒤에는 보고서의 명령 출력과 수치로 판단한다. 워커의 "통과했다"를 그대로 옮기지 않는다.
