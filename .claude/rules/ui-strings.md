# 화면 문구를 쓰고 고칠 때

화면 문구와 번역을 고칠 때 지키는 규칙이다. 리뷰는 규칙을 ID로 가리킨다.

## 쓰는 법

- **STR-1** 문구는 `String(ui:)`·`.ui(…)`로 쓴다.
- **STR-2** 새 문구와 고친 문구는 `swift scripts/i18n.swift sync`로 카탈로그에 넣는다.
- **STR-3** 카탈로그(`Sources/DJCrate/Resources/Localizable.xcstrings`)에 en·ja 번역을 채운다. en이 빠지면 `scripts/check.sh`의 번역 검사가 막는다.
- **STR-4** 쓰는 법, 문체, rekordbox 용어표는 `docs/i18n.md`에 있다.

## 편집·저장 화면 용어

- **STR-5** 편집·저장 화면 용어는 아래 표를 따른다. rekordbox에 하는 동작은 `저장`, USB에 하는 동작은 `쓰기`다. 화면에는 옛 이름 `초안`을 쓰지 않는다. `스냅샷`과 `반영`도 쓰지 않는다. 예외는 CLI 문구와 STR-6이다. CLI 문구는 명령 이름과 맞춰 `초안`·`스냅샷`이 남는다.
- **STR-6** XML 파일 안의 기존 재생 목록 이름(`DJCrate 반영`)은 유지한다.

| 동작 | 화면 용어 |
|---|---|
| 편집 이력 취소 / 다시 실행 | 실행 취소 / 실행 복귀 |
| 아직 저장하지 않은 편집 삭제 | 편집 버리기(큐·그리드·게인·태그·앨범아트·재생 목록은 대상을 함께 적음) |
| 저장 전 백업으로 라이브러리 전체 복원 | 저장 전으로 복원…(메뉴·팝오버·저장 대기 바, 늘 확인 창) / 저장 전으로 복원(결과 토스트, 바뀐 것이 없으면 바로 복원) |
| 편집을 rekordbox 라이브러리에 직접 저장(⌘S) | rekordbox에 저장 / rekordbox 저장 대기 |
| 저장하지 않은 편집이 있다는 표지(곡 목록 열·행 ●·사이드바·상태 줄) | 저장 대기 |
| 막힌 편집 복구 시트에서 고른 줄을 편집에 적용(rekordbox에는 쓰지 않음) | N줄 적용 |
| DJCrate가 편집·목록·기록을 자기 폴더에 남김 | 보관(「편집을 보관하지 못했습니다」. `저장`은 rekordbox 저장 전용) |
| rekordbox 라이브러리 복원 지점 | 복원 시점(`시점 스냅샷`이던 것) |
| 읽어 온 라이브러리 사본 | 「‘rekordbox와 동기화’를 한 뒤」·읽은 사본·읽은 시점(`스냅샷`이던 것) |
| USB에 반영 | USB에 쓰기 / USB 쓰기 대기(그대로) |
| 정해진 연동 파일에 XML 저장 | XML 만들기 |
| 저장 위치를 골라 라이브러리 전체를 XML 한 파일로 내보내기(읽기만) | 라이브러리 XML 내보내기… |
| DJCrate의 추가 목록에서만 빼기 | 추가 목록에서 제거 |
| rekordbox 컬렉션에서 곡 삭제 | rekordbox에서 빼기… |

## 목록 필터 용어

- **STR-17** 목록을 조건으로 줄이는 기능은 화면에서 "필터"라 부른다. 옛 이름은 화면 문구에 쓰지 않는다. 켠 조건은 칩에 글로 보인다. 칩을 줄일 때도 첫 조건은 글로 남긴다. 식별자 `minimumRating`은 바꾸지 않는다. `colorFilter`는 곡 색을 여럿 고르므로 `colorFilters`로 바꿨다.
- **STR-18** 사이드바 라이브러리 구역의 항목(코드 이름 `LibraryFilter`)은 화면에서 "필터"라 부르지 않는다.

## `…` 붙이기

- **STR-7** `…`는 누르면 늘 아래 창을 여는 버튼·메뉴에만 붙인다.
  - 확인 창
  - 시트
  - 이름 입력 창
  - 저장 위치 창
- **STR-8** 바로 실행하는 항목에는 붙이지 않는다. 예: XML 만들기, 실행 취소로 되돌리는 편집 버리기.
- **STR-9** 막힘·손실이 있을 때만 확인 창이 뜨는 항목에도 붙이지 않는다. 최종 확인 버튼에도 붙이지 않는다.
- **STR-10** 직접 저장 항목에는 붙이지 않는다. `rekordbox에 저장` 메뉴와 머리 줄의 저장·바로 넣기 단추가 그렇다. #210 뒤로 막힘·제외·손실이 있을 때만 확인 창이 뜨기 때문이다.
- **STR-11** 컬렉션에서 곡을 빼는 `rekordbox에서 빼기…`에는 붙인다. 메뉴의 `저장 전으로 복원…`에도 붙인다. 둘은 늘 확인 창을 연다.

## 툴팁과 안내

- **STR-13** 툴팁에는 라벨에 없는 정보만 쓴다. 아래 셋이다. 한 문장으로 75자 이내에 쓴다.
  - 아이콘만 있는 컨트롤의 이름. 단축키가 있으면 함께 적는다.
  - 비활성 이유. 원인과 할 일을 적는다.
  - 결과가 미치는 범위.
- **STR-14** XML 가져오기 절차는 연동 안내 창에서 설명한다.
- **STR-15** 수식키는 `⌃⌥⇧⌘` 순서로 적는다.
- **STR-16** 막힘·오류 이유는 무엇을 하면 되는지까지 한 문장으로 쓴다(AGENTS.md "말·코드 스타일").
- **STR-19** 라벨이 글자로 보이는 컨트롤에는 그 라벨을 풀어 쓴 툴팁을 달지 않는다. 라벨이 아이콘으로 바뀌는 폭에서만 이름을 알린다.
- **STR-20** 컨트롤 설명은 기본 0줄이다. 설정 섹션 footer는 한 문장(40자 안)까지 둔다. 라벨에 괄호로 정의를 붙이지 않는다.
- **STR-21** 한 화면에서 같은 이유는 한 곳에서만 말한다. 그 상태의 주 알림 자리를 하나 정한다.
- **STR-22** 안심 약속을 진입점마다 되풀이하지 않는다. 예: "아직 rekordbox에 저장하지 않았습니다", "음원 파일은 바뀌지 않습니다". 상태 표시가 맡는다. 저장 대기 표지, 저장 대기 수, 상태 줄이 그렇다.
- **STR-23** 처음 한 번만 필요한 개념은 ⓘ 팝오버에 둔다. 다른 앱의 메뉴 경로는 도움말 메뉴 안내에 둔다.
- **STR-24** 글로 남기는 설명은 아래 다섯 가지다. 이 밖의 설명은 화면 장치로 옮긴다. 옮길 수 없으면 뺀다.
  - 되돌릴 수 없는 손실. 확인 창의 손실 줄이다.
  - 지금 할 일이 있는 막힘(STR-16).
  - 쓰는 동안 "끝날 때까지 끄지·뽑지 마세요". 진행 표시 한 곳에만 둔다.
  - 빈 화면의 첫 행동 한 줄.
  - 필요한 순간에만 붙는 단서. 예: 편집이 있을 때만 붙는 필터 각주.
