# 화면 문구를 쓰고 고칠 때

화면 문구와 번역을 고칠 때 지키는 규칙이다. 리뷰는 규칙을 ID로 가리킨다.

## 쓰는 법

- **STR-1** 문구는 `String(ui:)`·`.ui(…)`로 쓴다.
- **STR-2** 새 문구와 고친 문구는 `swift scripts/i18n.swift sync`로 카탈로그에 넣는다.
- **STR-3** 카탈로그(`Sources/DJCrate/Resources/Localizable.xcstrings`)에 en·ja 번역을 채운다. en이 빠지면 `scripts/check.sh`의 번역 검사가 막는다.
- **STR-4** 쓰는 법, 문체, rekordbox 용어표는 `docs/i18n.md`에 있다.

## 편집·쓰기 화면 용어

- **STR-5** 편집·쓰기 화면 용어는 아래 표를 따른다.
- **STR-6** XML 파일 안의 기존 재생 목록 이름(`DJCrate 반영`)은 유지한다.

| 동작 | 화면 용어 |
|---|---|
| 편집 이력 취소 / 다시 실행 | 실행 취소 / 실행 복귀 |
| 아직 쓰지 않은 초안 삭제 | 초안 버리기(큐·그리드·게인·태그·앨범아트는 대상을 함께 적음) |
| 쓰기 전 백업으로 라이브러리 전체 복원 | 쓰기 전으로 복원…(메뉴·쓰기 대기 바, 늘 확인 창) / 쓰기 전으로 복원(결과 토스트, 바뀐 것이 없으면 바로 복원) |
| 초안을 rekordbox 라이브러리에 직접 쓰기 | rekordbox에 쓰기 / 쓰기 대기 |
| 정해진 연동 파일에 XML 저장 | XML 만들기 |
| 저장 위치를 골라 라이브러리 전체를 XML 한 파일로 내보내기(읽기만) | 라이브러리 XML 내보내기… |
| DJCrate의 추가 목록에서만 빼기 | 추가 목록에서 제거 |
| rekordbox 컬렉션에서 곡 삭제 | rekordbox에서 빼기… |

## `…` 붙이기

- **STR-7** `…`는 누르면 늘 아래 창을 여는 버튼·메뉴에만 붙인다.
  - 확인 창
  - 시트
  - 이름 입력 창
  - 저장 위치 창
- **STR-8** 바로 실행하는 항목에는 붙이지 않는다. 예: XML 만들기, 실행 취소로 되돌리는 초안 버리기.
- **STR-9** 막힘·손실이 있을 때만 확인 창이 뜨는 항목에도 붙이지 않는다. 최종 확인 버튼에도 붙이지 않는다.
- **STR-10** 직접 쓰기 항목(`rekordbox에 쓰기`·`rekordbox에 바로 넣기`)에는 붙이지 않는다. #210 뒤로 막힘·제외·손실이 있을 때만 확인 창이 뜨기 때문이다.
- **STR-11** 컬렉션에서 곡을 빼는 `rekordbox에서 빼기…`에는 붙인다. 메뉴의 `쓰기 전으로 복원…`에도 붙인다. 둘은 늘 확인 창을 연다.
- **STR-12** 툴바의 쓰기 메뉴 제목은 짧게 쓴다. 최소 창 폭에서도 보여야 한다.

## 툴팁과 안내

- **STR-13** 툴팁은 동작을 짧게 설명한다. 75자 이내를 권장한다.
- **STR-14** XML 가져오기 절차는 연동 안내 창에서 설명한다.
- **STR-15** 수식키는 `⌃⌥⇧⌘` 순서로 적는다.
- **STR-16** 막힘·오류 이유는 무엇을 하면 되는지까지 한 문장으로 쓴다(AGENTS.md "말·코드 스타일").
